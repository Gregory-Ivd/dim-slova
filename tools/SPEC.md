# Спецификация перевода и разметки — «Слово Боже»

Исходник: `slovo.txt` (в этой же папке), русский, конспект Библейской школы.
Итог: украинский текст в `content/chN.md` + тест в `content/quizN.json`.

## Перевод

- Полный и точный. Ничего не сокращать, не добавлять богословия от себя, не «улучшать» мысль.
  Исправлять только явные опечатки и русизмы. Стиль — живой литературный украинский, не калька.
- Обращение к читателю сохранить как в оригинале («ти»/«ви»).
- Апостроф — только ’ (U+2019). Кавычки «ёлочки», внутри „лапки“. Тире — « – » (короткое с пробелами, как в переводе УБТ).
- Оригинал говорит о «русском слове» в разделе о значении слов — адаптировать к украинскому («не українські слова», «значення українського слова недостатньо»).
- **Тексты Библии не переводить и не писать самим.** Только маркер (см. ниже). Тексты подставит сборщик
  дословно из «Біблія. Сучасний переклад» (УБТ).
- Ссылки в прозе (не цитаты) писать по-украински, названия книг — ниже. Номера псалмов в прозе
  оставь как в оригинале, но пометь `[[Пс 118:89]]` — сборщик пересчитает.

## Разметка `chN.md`

```
# I. Писання – це Бог, Який говорить до нас {#ch1}
(механізм написання Біблії)            ← подзаголовок раздела, первая строка после # в круглых скобках

## 1. Заголовок подраздела {#ch1-s1}
### Малый заголовок                     ← напр. «Слово Боже корисне для:», «Чому важливо зберігати Слово в серці?»

Обычный абзац. **Жирным** — ключевые термины при первом появлении, 1–3 на подраздел, не больше.

@@ 1-я Царств 15:1-13                   ← цитата Писания. Ссылку писать ТОЧНО как в оригинале, по-русски.
                                           Одна строка = одна цитата. Текст цитаты НЕ писать.

!! Главная мысль.                        ← выноска «Головна думка». Только фраза из самого текста оригинала
                                           (переведённая), без новой мысли. 1–2 на подраздел, где есть явный вывод.

>> Пояснення.                            ← второстепенная врезка: значение слова, исторический фон, пример.
                                           Тоже только из текста оригинала. Не дублировать абзац — перенести.

- пункт списка
  продолжение пункта (абзац-пояснение к пункту) — отступ два пробела

{{Q:Матф.20:15}}                         ← короткая цитата внутри абзаца (в оригинале стих приведён в кавычках
                                           внутри прозы). Ссылку — как в оригинале. Если в оригинале цитата
                                           неполная, после маркера в квадратных скобках — русский фрагмент:
                                           {{Q:Ис.59:1|рука Господа не сократилась}}
```

id: главы `ch1`…`ch5`, подразделы `ch1-s1`, `ch1-s2`… Если в главе нет нумерованных подразделов
(как в главе I), разбей на смысловые подразделы `##` с заголовками, взятыми из сути текста, 4–7 штук, —
и отметь это в отчёте.

## Тест `quizN.json`

Цель — выявить, насколько глубоко человек усвоил материал, а не угадал. 14–18 вопросов.

```json
{ "chapter": 1, "title": "…", "questions": [
  { "id": "q1-01", "type": "single", "level": "знання|розуміння|застосування",
    "q": "Текст питання", "options": ["…","…","…","…"], "answer": 2,
    "explain": "Чому саме так, з опорою на текст уроку і посиланням (напр. Ів. 14:23–24).",
    "anchor": "ch1-s2" },
  { "type": "multi",  "options": [...], "answer": [0,2] },
  { "type": "truefalse", "q": "Твердження…", "answer": false },
  { "type": "match", "q": "…", "pairs": [["Посилання або поняття","Відповідність"], ...] },
  { "type": "order", "q": "…", "items": ["перший","другий","третій"] },
  { "type": "reflect", "q": "Питання для роздуму", "sample": "Орієнтир відповіді з тексту уроку" }
]}
```

Требования:
- Не меньше: 5 `single`, 2 `multi`, 2 `truefalse`, 1 `match`, 1 `order`, 1–2 `reflect`.
- Не меньше 5 вопросов уровня «застосування»: ситуация из жизни, человек говорит/делает X —
  какую ошибку он совершает по уроку, что посоветовать, какой принцип нарушен.
- Не меньше 3 вопросов «какое место Писания подтверждает мысль / о чём говорит место X».
- Дистракторы правдоподобные: частично верные, «почти как в уроке», популярные заблуждения.
  Никаких «все ответы верны», никаких очевидно абсурдных вариантов.
- Правильный ответ однозначно выводится из текста урока. Никаких вопросов по фактам, которых в уроке нет.
- Позиция правильного ответа в `single` — разная, не всегда одна и та же.
- Цитаты Библии в вопросах и вариантах не приводить дословно — только пересказ смысла и ссылка.
- `explain` обязателен для всех, кроме `reflect`; 1–3 предложения.
- Язык — украинский.

## Отчёт форка (коротко)
1. Список всех маркеров `@@` и `{{Q:…}}` в порядке появления.
2. Что в оригинале показалось ошибкой или спорным (без правки) — одной строкой на случай.
3. Сколько вопросов каждого типа.
